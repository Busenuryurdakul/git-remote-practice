# Git Remote Practice

Practice repository for connecting a local Git repo to a remote on GitHub.

## Tasks Completed

1. **Created a remote repository** on GitHub (empty, public)
2. **Connected local repository** with `git remote add origin <url>`
3. **Verified the connection** with `git remote -v`

## Commands Used

```bash
git init -b main
git remote add origin https://github.com/Busenuryurdakul/git-remote-practice.git
git remote -v
git push -u origin main
```

## Remote Verification

```
origin  https://github.com/Busenuryurdakul/git-remote-practice.git (fetch)
origin  https://github.com/Busenuryurdakul/git-remote-practice.git (push)
```
